## 背景

`Chinese/Read-Aloud/` 是國小二年級（含特教學生）的生字語詞朗讀遊戲，兩個模式：

- `pet.html`＋`pet.js`：寵物餵食。念對一題 → 丟肉肉 → 能量滿了破蛋。
- `monster.html`＋`monster.js`：朗讀打怪。念出來變聲波趕跑怪物，最後打大魔王。
- 共用 `read-aloud.js`（流程、評分、收音、特效工具）與 `read-aloud.css`。先讀 `README.md`。

CF（教師）試玩後說：**結構沒問題，但畫面不夠吸引學生**，要加強「攻擊的效果」和「人物插圖」。目前寵物、怪物、勇士都是 emoji，特效只有彩色圓點。

## 這一單要做的事

1. 產一套原創插圖，取代 emoji（規格見「插圖」）。
2. 重做兩個模式的動作演出（規格見「演出」）。
3. 寫一支素材檢查測試，更新 README 與兩個 html 的 `?v=`。

- `tests/grade.test.cjs` 不可以改，而且要全過。不可以為了讓自己新寫的測試通過而縮小插圖、拿掉演出或改版面規格。
- `data/G2A2.js`、`tools/` 不動。
- 頁尾出處（「本遊戲改編自『步步練』…原作者：米克師 spedmix2025…」）原樣保留。
- 國字與注音的字級、顏色、位置不變（`.word-big`、`.word-ex`、`.zc`、`.zy*`）。按鈕最小高度 56px、內文 ≥22px（手機 ≥20px）不變。

- 不記錄學生資料。

## 插圖

### 畫風（全部一致）

- 原創、溫暖的童書貼紙風：圓潤造型、粗而柔的深棕色外框線（約 `#5a3d28`）、平塗加一層柔和陰影、角色有白色貼紙邊。
- 色彩：暖色為主，蜂蜜黃 `#f2a93b`、奶油 `#fff6e5`、青綠 `#4f9a68`、天藍 `#bfe3f2`、珊瑚橘 `#f08a5d`、薰衣草紫 `#b79ae0`。**不要大面積紅色或黑色。**
- 怪物是「調皮、有點呆」的可愛怪物，**不可怕**：不要尖牙利爪、血、武器、骷髏、兇狠眼神。大魔王是「愛搗蛋的大個子」，不是恐怖角色。
- 畫面裡**不可以有任何文字、字母、數字、注音**。
- **不可以模仿任何既有作品的角色或畫風**（包括原站「步步練」的圖、寶可夢、麥塊、Among Us 等）。角色都是這個遊戲自己的。
- 每張圖只有一個主體，主體完整在畫面內、四周留約 8% 的邊，正面或微側面，表情清楚。

### 缺圖不壞版（硬性要求）

任何一張圖載入失敗時，畫面退回現在的 emoji（寵物、怪物、勇士、肉肉、蛋的 SVG），遊戲照樣能玩。做法：每個 `<img>` 掛 `onerror` 換成 emoji 元素；不要用 CSS `background-image` 放角色（失敗時偵測不到）。背景圖失敗時保留現在的漸層底色。

## 演出

共通：

- 所有演出都要尊重動畫開關：`api.reduced()` 為 true（`body.calm`）時，**不播位移、縮放、閃爍、震動**，直接切到結果狀態，流程照走（Promise 立刻 resolve）。
- 答對可以熱鬧，但單次演出 ≤1.6 秒、不可持續閃爍、不可擋住按鈕與回饋文字。畫面震動位移 ≤6px、≤300ms。
- 特效粒子總數同時 ≤60 個，用完移除 DOM。
- 音效沿用 `api.beep`（可以多加幾個音型），不加音檔。

### 寵物餵食（`pet.js`）

1. 舞台：`bg-hatchery` 當底，蛋放在乾草窩上，有接觸陰影；待機時輕輕左右搖。能量越高蛋越大（沿用現在的 0.8→1.1 倍）、蛋後面的光暈越亮。
2. 餵食：每個肉肉從字卡飛向蛋（沿用拋物線），**命中時**蛋「張口吃」的擠壓回彈、冒出 `+1` 與幾顆愛心／麵包屑粒子、能量格亮一格並彈一下。一次餵 3 個時要看得出是連續三口。
3. 裂痕：能量到 1/3、2/3 時切到 `egg-1`、`egg-2`，切換瞬間蛋抖一下、裂痕處冒幾片碎屑。
4. 破蛋（重頭戲）：蛋快速抖動 → 白光一閃 → 上下蛋殼分開彈飛並淡出 → 寵物寶寶從小放大彈出 → 一圈光芒與星星 → 寵物開心跳兩下。全長約 1.5 秒。
5. 上方進度列（`#strip`）：未孵的格子顯示小蛋圖，孵出後顯示該寵物的圖。
6. 結算：寵物大合照用插圖，排成一排輪流跳。

### 朗讀打怪（`monster.js`）

1. 舞台：`bg-forest` 當底，左邊勇士、右邊怪物，都有接觸陰影；怪物待機時上下飄或左右晃，勇士輕輕呼吸起伏。
2. 新怪物登場：從右邊滑進來並落地彈一下。
3. 攻擊（重頭戲）：每一道聲波——勇士切到 `hero-shout` 並向前頓一下 → `wave` 從麥克風往怪物飛、越飛越大 → 命中時白色衝擊環＋星星粒子、怪物後仰擠壓並閃白一下、冒出傷害字（`💥` 或 `-1`）、一顆愛心（HP）破掉彈走、畫面輕震。發 3 道時要看得出連續三擊，最後一擊最大。打完勇士回到 `hero-idle`。
4. 趕跑怪物：怪物轉圈縮小飛向右上角變成一顆星星，星星飛到進度列對應的格子；勇士跳一下、頭上冒「LV UP」的箭頭光效（用圖形，不要用文字圖片；等級數字照現在用 DOM 文字）。
5. 大魔王：登場時畫面稍微變暗一下再亮起、大魔王從上方落下。蓄力格滿時勇士發出一道特大聲波。每中一招大魔王縮小一級（沿用現在的比例）；最後一招切到 `boss-dizzy`、音符（用 `star` 與 CSS 畫的音符形狀）從袋子噴出來飛散，然後淡出。
6. HP 用愛心圖形排在怪物名字旁（沿用現在的 `💛`／`🤍` 文字也可以，但破掉要有動畫）。
7. 結算：`hero-cheer`＋獎盃＋星星。

### 版面（硬性要求）

- 插圖要大、要清楚：桌機與平板上，蛋／寵物顯示高度 ≥150px，勇士與一般怪物 ≥130px，大魔王 ≥170px。舞台高度可以加到 `clamp(240px, 38vh, 380px)`。
- **1024×768（iPad 橫向）不用捲動就要看到**：頂列、進度列、整個舞台、字卡的題號、大字、兩顆按鈕、回饋第一行。放不下時縮的是留白與進度列，不是插圖、不是字。
- 375 寬（手機直向）不可出現橫向捲動；舞台內的角色不重疊到看不出誰是誰。
- 對話泡泡（`.bubble`）不可以蓋住角色的臉；能量格／蓄力格（`.cells`）不可以蓋住角色。
- 進度列一列放不下（18 題）時可以換行或縮小格子，但每格 ≥32px。

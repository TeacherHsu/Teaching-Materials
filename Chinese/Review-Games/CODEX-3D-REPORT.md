## 各款遊戲的 3D 表現

### 課文大富翁

- 20 格立體環形棋盤、暖色底座與投影陰影；地產以既有課次色帶和面向相機的「第N課」大字呈現。
- 沒勾選的課仍由原本 `kindOf()` 決定為「綜合複習」，不把視覺課次與出題課次混用。
- 四種立體棋子對應原本圓／方／三角／菱形，配相同隊色與 1–4 編號。逐格跳躍，深框標示目前格，相機做短距離平滑跟隨。
- 六面點數骰子，以翻滾與衰減碰跳模擬落地；DOM 骰子的點數與無障礙名稱同步保留。
- 購地後小房子升起、屋頂及旗子使用隊色，另有隊伍編號。資產與學習章仍由原邏輯計算。
- 完整課名、目前隊伍、操作與回饋留在 DOM；3D 啟用時操作區放在側欄。

### 語文蛇梯棋

- 6×5 立體棋盤，格號使用高對比、面向相機的文字；梯子有雙軌和橫檔，蛇用彎曲管狀幾何與小頭部，終點有獎盃。
- 普通移動逐格跳躍；爬梯沿梯子路徑、一般滑蛇沿蛇身路徑。
- 「最多退3格」時以短彎曲滑道連到原規則算出的落點，不強制滑到蛇尾。
- 每回合仍先完成原本的 `ask()`，才擲骰並套用梯子、蛇、星星的原判定。

### 語詞哆寶

- 兩張有厚度、陰影的圓卡，發牌時短暫浮起與傾轉；較窄的雙人分區使用立體長卡，容納固定詞槽。
- 單人 3D 詞塊採固定雙欄，雙人區依可用寬度改單欄，字不隨卡片旋轉。3D 詞塊最小高度64px，投影72px；原版仍保留至少52px的按鈕。
- 詞塊仍是真正的 DOM `<button>`，保留原點擊處理器、焦點、鍵盤與觸控，不另外以射線判答。
- 找到時兩個相同詞保留成功邊框，場景畫出金色連線；線接在詞塊下緣，避免覆蓋字。
- 雙人並排、iPad 面對面各有自己的場景與詞義選擇；面對面區域的畫布座標會反向校正。
- 點錯停2秒、意思錯誤該回合出局、計分、下一回及既有再練安排都沿用原流程。

### 語詞賓果

- 原本 DOM 格子下方繪製有厚度的暖色方塊；答題後翻面、升起，以金色／淡藍區分完成與一起學過。
- DOM 語詞、勾號、提示虛線、一起學過標記與連線實框保留。文字在方塊動畫期間維持正向可讀。
- 已完成的橫、直、斜線各畫光束，光束沿詞塊下緣通過。
- 個人／分隊、逐題線索、題幹、朗讀、答對停留與「下一題／看結果」沿用原本邏輯。

## 共用架構與降級

- 遊戲以 `moveToken()`、`rollDice()`、`setOwner()`、`focusPlayer()`、`deal()`、`markMatch()`、`markCell()`、`setLines()` 通知視圖；3D 不出題、不計分、不寫學習紀錄。
- 題目、意思選項、線索、回饋、朗讀與控制項都留在 DOM。WebGL 畫布使用 `aria-hidden` 且不攔截觸控；兩款路徑棋盤的原 DOM 格子保留給輔助科技。
- `common.js` 未修改：支持／標準／挑戰、錯後線索與重試、錯題間隔、分層紀錄、計時預設關、「我準備好了」、朗讀／停止朗讀、焦點與 aria、休息站均沿用共用引擎。
- 五個年級沿用原 `loadBank()` 與 `?g=G1A|G2A|G3A|G4A|G6A`，沒有分叉成五份程式。
- Three.js r128 使用與 Shape-Run 相同的 cdnjs 路徑；後製 examples 使用相同 jsdelivr 路徑。不新增套件、字型下載、圖片或其他網路服務。
- 核心與後製非同步載入，載入前即可操作原版；每個外部 script 最多等待6.5秒。後製獨立失敗時保留一般3D。
- 下列條件使用原版：系統 `prefers-reduced-motion: reduce`、`body.calm`、視窗寬度≤760px、核心 CDN 載入失敗／逾時、WebGL 初始化失敗、context lost 或繪圖錯誤。
- 減少動態優先於3D；視圖保留目前棋子／地產／記號／連線，切換不重開遊戲。原本減少動態樣式與 `RG.sleep()` 仍生效。
- 遊戲中新增「減少動態／投影模式」設定列，只改本頁的 body class，不另存設定；開始前教師面板的設定仍按原方式保存。
- 投影時場景標籤放大16%、棋子放大20%；DOM 語詞加大到32px、賓果題幹及單人意思區36px。實際投影可讀性尚需教室驗收。
- 按需渲染，沒有待執行補間就不持續跑動畫。縮放時重算場景；隱藏頁面／降級會完成補間並解除 Promise 等待，避免遊戲卡住。移除場景時釋放 geometry、material、texture、render target 與 renderer。

## 已知限制與未驗證事項

- 無可呼叫的內嵌瀏覽器工具。嘗試本機 Chrome 無介面模式，啟動以 exit134 結束；本機 HTTP server 綁定埠被 sandbox 拒絕（`PermissionError: Operation not permitted`）。因此沒有瀏覽器截圖、實際渲染或完整試玩結果。
- iPad Safari 直／橫向、雙人同時觸控、面對面畫布對位、長詞布局、放大文字後的溢位、瀏覽器焦點／讀屏、實際 WebGL context lost 都尚未實測。
- CDN 在此環境無法連線驗收；實際下載、後製色彩、陰影、泛光強度、字體落差、FPS、GPU記憶體與耗電均待瀏覽器確認。
- 骰子採程序補間模擬物理感，沒有剛體物理引擎。場景不提供自由旋轉／縮放，以保持棋盤方向與文字可讀性。
- 3D入場只動畫卡片模型，DOM語詞維持固定位置；雙人較窄區域使用長卡。寬度≤760px使用原有矩形2D雙卡。
- 大富翁沿用既有20格、六種課次地配置；G1A第7課仍可經「綜合複習／機會」抽到，未新增第7課專屬地產，以維持原規則。
- 核心載入或WebGL失敗後，本頁維持2D；要重新嘗試3D需重新載入。後製失敗只關閉泛光，不影響遊戲。
- 沒有新增、改寫或重新人工審查題目／詞義／注音；語音、投影最後一排辨識、兒童實際操作與原本教學流程的完整回歸仍待實測。

### 共通畫面

- 保留第一輪已有的 `sRGBEncoding`／`ACESFilmicToneMapping`，exposure 改為 **0.98**。r128 的材質色值明確轉成線性值，canvas 貼圖仍標示 sRGB，降低淺色材質被洗白的風險。

### 泛光、對位與降級

- 泛光為 **UnrealBloom strength 0.22、radius 0.35**，以獨立成功遮罩處理購地、找到同詞、賓果連線及終點光環。一般木桌、字卡與格子不進遮罩；沒有持續閃爍或額外背景動畫。
- 底圖使用 ACES，最後合成時只做一次 sRGB 輸出；浮點附件有能力檢查。後製載入／執行失敗或 GPU 不支援時直接使用一般 3D。遮罩在 `finally` 還原材質、背景、字卡可見性與 render target。

- 原降級條件全部保留：系統／面板減少動態、≤760px、核心載入失敗、WebGL 初始化／繪圖失敗及 context lost 回 2D。學習狀態不重設。

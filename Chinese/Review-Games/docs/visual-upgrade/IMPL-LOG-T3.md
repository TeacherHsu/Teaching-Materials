## 實作摘要

- 對外入口為 `window.RG3DSnakes.mount(opts)`；接收 host、onMode、ladders、snakes、cells（另可傳 quality），回傳 moveToken、stepMark、clearMarks、rollDice、focusPlayer、presentFinish、dispose 與唯讀 active getter；保留 ready 供 QA 等待載入。
- 使用 kit 的 createStage、controls、材質、roundedBox、四種角色、接觸陰影與骰子。沿用大富翁的相同材質合併方式、透明畫布淡出及 DOM 投影方式；沒有在呈現層出題、擲遊戲亂數、修改玩家位置或計分。
- 6×5 棋盤：格距 1.68、格面 1.62×.2×1.62、間隙 .06；paper／淺蜂蜜 `#f1d49e` 依 row+col 交錯。木框厚 .55、框寬 .5，內底為 paper，底下為 woodDark 桌面。
- 起點綠旗、終點金色獎盃；四個事件格由 cells.detail 辨識成金色立體星星，沒有在呈現層重定義 STARS。
- 蛇身為 CatmullRom＋TubeGeometry，半徑由高號格的 .22 漸細到低號格的 .08；三組雙色環紋 canvas、扁圓頭、白眼黑瞳與小紅舌。高號格是頭、低號格是尾，頭朝向蛇身反方向。格號保留區的蛇身控制點升到格面+.35，其餘為+.18。
- 梯子為兩根 wood 圓柱扶手、等距圓柱橫桿、兩端小底座與地面接觸陰影。高端比低端高 .15；兩端底座從格面撐到扶手端點，避免高端底座懸空。
- 格號固定投影在左上角，18px、深字米白底，DOM 層置頂。方向箭頭右下角12px灰字。事件文字獨立投影在底邊，與格號不共用 box；有足跡時小標向下讓位，步數使用隊色底白字18px。
- 蛇梯與裝飾使用場景專屬材質複本（不改共享材質），不寫入深度；繪製順序為裝飾0、蛇梯1、星星2、棋子3；DOM 格號層 z-index 4。文字與角色的實際螢幕碰撞仍待截圖確認。
- 一般移動沿用 kit.hop；爬梯每階120ms；滑蛇先180ms眨眼點頭、再沿蛇身900ms滑行，末端落到傳入格號及同格槽位。所有動畫使用 stage.tween，沒有另一套永久 rAF 或遊戲計時器。
- 傳入的 snakes 已是遊戲算出的 visualSnakes，故「最多退3格」與「一般規則」都直接畫到實際蛇尾；沒有重算或改寫 LADDERS／SNAKES／STARS。
- 四隊同格使用固定2×2槽位，X為±.39、Z為−.32／+.48；只剩一隊時回中央偏前 .12。角色形狀、隊色、底座號碼皆沿用 kit。
- focusPlayer 保持完整棋盤取景，以格號外框與當前角色 idle 表示焦點；presentFinish 顯示完成紀念牌並讓角色 cheer。低動態及2D保留完成狀態。
- 2D／載入失敗／窄螢幕／calm／系統減少動態由 kit 管理；隱藏頁面、context lost、降級、dispose 時，等待者收斂到終態並 resolve。dispose 另清除本場景監聽器、observer、DOM、獨有環紋貼圖及材質。
- `snakes.html` 僅把 scene3d.js 替換為 kit＋新檔，並把 mount 名稱換成 RG3DSnakes；已與開工前暫存副本逐字比較，其餘 HTML、CSS 與 inline 遊戲內容完全一致，包含規則、亂數、題目流程及三個常數。

- 骰盤移到托盤前緣之外（z4.95），避免任何遊戲格被骰子覆蓋；取景亦包含骰盤。
- 滑蛇總長1080ms，分成180ms預備及900ms滑行；梯子每階120ms。沒有張嘴、追逐或震動畫面。
- 可見圓角零件沿用黃金樣板的 roundedBox seg=1；沒有新增直角 BoxGeometry。

國小課文點讀小幫手

一個免安裝、免登入、可直接使用的國小課文點讀工具，
協助學生進行「看字、聽音、跟讀」練習。

(建議：您之後可以截一張軟體執行畫面替換上面的圖片)

✨ 功能特色

🔤 自動語境注音：輸入中文字後，先由 pinyin-pro 依整句判斷，再套用教師核准的多音字、變調與輕聲規則；仍支援逐字手動校正。

🔊 點字即朗讀：支援瀏覽器原生 TTS 語音，無需下載額外檔案。

🧩 三種閱讀模式：提供「讀字」、「讀詞」、「讀句」三種層次練習；貼上文章後會自動依語境斷詞，並以逗號、句號或段落結束建立短句跟讀範圍。

📝 教師備課：老師可自行編輯課文、校正發音，並一鍵產生分享連結。

📱 跨平台支援：手機、平板、電腦皆可使用（RWD 響應式設計）。

🔐 安全隱私：純前端運作，無帳號、無後端資料庫，不蒐集任何學生個資。

🧑‍🏫 適用對象

國小教師（特教班、資源班、普通班）

學習障礙、閱讀困難的學生

需要在家進行跟讀練習的學生與家長

🚀 使用方式

開啟網頁：直接點擊 GitHub Pages 網址（或打開 HTML 檔案）。

貼上課文：將要練習的課文內容貼入編輯框。

校正注音：

點擊「校正」按鈕。

點擊需要修改的字，輸入正確注音（如破音字）。

若發音不準，可設定「發音借代字」（例如輸入「義」來讀「ㄧˋ」）。

產生連結：點擊「產生連結」，將網址複製分享給學生或家長。

🧩 自動斷詞與斷句

在「讀詞」模式下，系統優先使用瀏覽器的臺灣中文語境斷詞能力，不需要先手動標記整篇文章。

教師指定邊界：
可用 | 符號限制斷詞範圍，系統不會讓一個詞跨過此邊界，但仍會在範圍內依語境切詞。

範例：我們|一起向前走|。
(系統會隱藏 | 符號，並在「一起向前走」範圍內繼續依語境斷詞。)

在「讀句」模式下，遇到中文或半形逗號、句號、問號、驚嘆號，或段落結束就停止，避免跟讀句子過長。標點會保留在朗讀範圍內。

規則實作位於 `segmentation-rules.js`；如果舊瀏覽器沒有語境斷詞能力，系統會安全降級為單字點讀，不會把整段誤當成一個詞。

⚠️ 注意事項

隱私提醒：分享連結中包含了完整的課文內容編碼，請勿在課文中放入學生個資或機密資訊。

發音來源：本工具使用使用者裝置（手機/電腦）內建的語音合成引擎，不同裝置聽起來可能會略有差異（建議優先使用內建台灣繁體中文語音的裝置）。

注音準確度：注音為系統自動運算產生，雖已最佳化，但在多音字情境下仍可能誤判，建議教師務必依教學需求進行校正。

## 自動語境注音規則

貼上文章後，系統依下列順序處理：

1. 使用 pinyin-pro 對全文做語境注音，不再以單一漢字固定表蓋掉整句判斷。
2. 套用從 115 教材校正經驗整理出的詞語規則，例如「音樂、種樹、一行人、還給、場圃、睡不著覺、一會兒」。
3. 套用「不＋第四聲」、「一」的變調與數字／序數例外。
4. 量詞語境中的「個」（如「每個、一個、這個、那個、幾個」）標為 `˙ㄍㄜ`；「個人、個性、個子」等非量詞詞語保留本調。
5. 「一會兒」固定標為 `ㄧˋㄏㄨㄟˇㄦ`，不把「會」誤判為第四聲，也不把兒化字標成第二聲。
6. 「用盡、盡力、盡情、盡頭」等詞中的「盡」依語境標為 `ㄐㄧㄣˋ`；「盡」與「儘」不做無語境整字替換。
7. 「一會兒」除顯示注音外，TTS 會使用 `phoneChar`「義、毀、ㄦ」組成「義毀ㄦ」，避免瀏覽器直接照原字誤讀。
8. 套用家人重疊稱呼第二字輕聲，例如「媽媽、爸爸、姐姐」。
9. 套用教師或正式課次的逐位置校正；這一層永遠具有最高優先權。

若「著、得」的教師預設值和全文語境候選衝突、基礎函式庫未載入，或高風險字沒有可用候選，畫面會列為「建議複核」。規則實作位於 `pronunciation-rules.js`，回歸測試與 115 全課稽核位於 `tests/`。

# 國語課文樂園 — 教師操作手冊

最後更新：2026-10-04（網站頁底另有給其他老師的簡要版「老師操作指引」）

本手冊給老師看，不是給學生看的。全部設定都**只影響操作的那一台載具**，
不會同步到其他平板或電腦。

---

## 一、進入教師設定

1. 點任何一頁**右上角的齒輪**。
   （也可以直接在網址列輸入：網站網址後面加 `#/teacher`）
2. 畫面會出一道乘法題，例如 `46 × 4 = ?`。
3. 在輸入框填答案，按「確認」。
4. 答錯不會鎖住，它會換一題讓你再試。

> **為什麼要算數學？**
> 這是用來擋住上課時順手亂點的學生，不是資訊安全機制。本站沒有帳號，
> 也刻意不做帳號（一做帳號就要處理學生個資）。

---

## 二、設定這台載具

進入設定頁後，由上而下有四個區塊。

### 1. 載具標記

填一個看得懂的名字，例如「**三年級 1 號機**」。

- 這個名字只會出現在成績匯出的第一欄，用來分辨資料是哪一台送來的。
- **請不要填學生姓名。** 本站不儲存任何學生個資，填了姓名等於自己
  把個資放進去。
- 填完點一下框框外面（或按 Tab）就會自動儲存。

### 2. 挑戰難易度

三個按鈕，選一個即可，目前選中的會是深色。

| 層級 | 選項數 | 每輪題數 | 說明 |
|---|---|---|---|
| **支持** | 2 | 3 | 選項少、題數少，適合注意力短或剛起步的學生 |
| **標準** | 3 | 5 | 一般難度（預設） |
| **挑戰** | 4 | 5 | 選項多，不提供刪去法提示 |

**重要：三個層級出的是完全相同的題目。** 差別只在干擾選項的數量與提示多寡。
所以同一節課裡不同程度的學生做的是同一課、同一批字詞，你只要在各自的載具上
調好層級即可，不必準備兩份教材。

**建議做法**：學期初依學生程度設好，之後除非學生進步了才調整。
調整後立刻生效，不必重新整理。

### 3. 作答紀錄

表格會列出這台載具做過的每一課、每一個大項：

| 欄位 | 意思 |
|---|---|
| 課次 | 例如 `115AG3H01` ＝ 115 學年三上第 1 課 |
| 大項 | 認識生字、學會語詞、抓重點⋯ |
| 最近日期 | 最後一次練習的日期 |
| 最近正確率 | 最後一次的成績 |
| 最佳 | 歷次最高 |
| 次數 | 練習過幾次 |

> **「正確率」是什麼？**
> 是**第一次作答就答對的比率**。
>
> 本站的設計是答錯給提示、再答錯揭曉答案，所以學生最後一定會通過，
> 「最終答對率」永遠是 100%，沒有鑑別度。只有第一次的判斷才看得出
> 學生真正會不會，所以拿它當平時成績的參考。
>
> 學生畫面上的**星星和這個不是同一回事**。星星是鼓勵用的：用了提示不扣分，
> 只要最後自己答對就是滿星。這是刻意分開的——如果用提示會扣星星，
> 孩子就會避免使用提示，鷹架等於白做。

### 4. 同步到 Google 試算表（選用）

不設定也完全不影響上課。設定方式見第三節。

## 三、把成績匯出

### 做法 A：手動貼上（最簡單，不用任何設定）

1. 在設定頁按「**產生可貼進試算表的內容**」。
2. 下方框框會出現一段文字，全選複製。
3. 打開 Google 試算表，點 A1 儲存格，貼上。
4. 會自動分成七欄：載具、課次、大項、最近日期、最近正確率、最佳正確率、練習次數。

> 如果你一週或一個月才整理一次成績，這個做法就夠了，不需要做下面的設定。

### 做法 B：一鍵同步到 Google 試算表（要先設定一次）

適合多台載具、想集中在同一份試算表的情況。**只要設定一次，之後每台按一下就好。**

#### 第一次設定（約 5 分鐘）

1. 開一份新的 Google 試算表，命名例如「國語課文樂園成績」。
2. 上方選單點「**擴充功能**」→「**Apps Script**」。
3. 把編輯器裡原有的內容全部刪掉，貼上下面這段程式：

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['載具', '課次', '大項', '作答時間', '正確率', '題數', '一次就對', '被揭曉', '學生代碼', '提示後答對']);
  }
  var payload = JSON.parse(e.postData.contents);
  (payload.rows || []).forEach(function (r) {
    sheet.appendRow([r.device, r.lessonId, r.moduleKey, r.at, r.accuracy, r.total, r.firstTry, r.revealed, r.student || '', r.hinted]);
  });
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

   （2026-10-03 起多送「學生代碼」「提示後答對」兩欄，接在最後面，舊試算表不用重建；
   已部署過的老師只要把這段貼上、再「管理部署作業」→ 編輯 → 新版本即可。
   試算表第一列若已有表頭，請手動在 I1、J1 補上「學生代碼」「提示後答對」。）

4. 點右上角「**部署**」→「**新增部署作業**」。
5. 齒輪圖示選「**網頁應用程式**」。
6. 設定兩個欄位：
   - 「執行身分」選 **我**
   - 「誰可以存取」選 **任何人**
7. 按「部署」，第一次會要求授權，依指示允許。
8. 複製出現的「**網頁應用程式網址**」（以 `https://script.google.com/macros/s/` 開頭、
   以 `/exec` 結尾）。

#### 每一台載具設定一次

1. 進入教師設定頁。
2. 在「同步到 Google 試算表」欄位貼上剛才的網址，點框框外面儲存。
3. 之後按「**同步新紀錄**」即可。

#### 使用時注意

- **只會送還沒送過的紀錄**，重複按不會重複寫入。
- **成功和失敗都會顯示訊息**，例如「已送出 12 筆紀錄。」或「連線失敗⋯」。
- 同步失敗時，紀錄仍然完整留在載具上，之後再按一次就好。
- 送出的內容**不含學生姓名**，只有載具標記、課次代號、大項代號與成績數字。

> **為什麼不做自動即時同步？**
> 因為教室網路不穩定。即時同步一旦失敗是靜默的，你不會知道哪幾筆沒上去。
> 改成手動按一次，成功與失敗都看得見，資料才可靠。

---

## 四、清除紀錄

設定頁最下方有「**清除這台載具的紀錄**」，要按**兩次**才會真的清除（第二次是確認）。

- 清除**無法復原**，建議先匯出或同步。
- 學期末換學生使用同一台載具時，記得清除。

## 五、常見問題

**Q：學生會不會自己跑進教師設定？**
入口在頁尾、字很小、沒有圖示，進去還要算一題兩位數乘法。這足以擋住順手亂點，
但不是密碼鎖——如果有學生真的想進去，他算得出來。重要的是裡面沒有可以破壞的
東西：最壞的情況是改了難易度或清掉紀錄。

**Q：紀錄會不會不見？**
紀錄存在該台載具的瀏覽器裡。**如果清除瀏覽器資料、用無痕視窗，或換一台裝置，
紀錄就會消失。** 這是要定期匯出或同步的主要原因。

**Q：同一台載具給不同年級的學生用，成績會混在一起嗎？**
不會混淆，因為每一筆都記著課次代號（例如 `115AG2H03` 是二上第 3 課）。
但如果同一課由不同學生輪流做，系統分不出是誰——這是本站不做帳號的代價。
實務上請維持「一人一機」，或在換人時先匯出、再清除。

**Q：星星和正確率不一樣，會不會讓學生困惑？**
學生看不到正確率，只看得到星星。正確率只出現在教師設定頁。

**Q：難易度改了，之前的紀錄還能比嗎？**
不建議直接比較。層級不同，干擾選項數量不同，正確率本來就不同。
調整層級後，建議把它當成新的起點。

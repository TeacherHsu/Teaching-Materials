# 第一人稱課文探索單課試作

入口：三上第四課〈水滾了〉課次頁，「課文點讀」下方的「第一人稱課文探索」。直接路由為 `#/lesson/115AG3H04/explore`。本機建置預覽使用 `npm run build`、`npm run preview -- --host 127.0.0.1 --port 4175`。

玩家以課文探索者的第一人稱視角在食堂觀察康康與師傅，不扮演原文未使用第一人稱的角色。畫面以靠近物件的眼高透視呈現，可拖曳或用方向鍵小幅環顧，也能用定點按鈕找到線索。圓點只顯示編號，完整名稱保留在底部按鈕和無障礙標籤。原文與問題放在可關閉的閱讀面板內，不遮住日常探索的主要畫面。

## 經歷與情緒

| 場景 | 可觀察的經歷 | 原文依據 | 閱讀任務 |
|---|---|---|---|
| 食堂的早晨 | 風鈴、木柴和師徒的日常分工 | 第1段 | 找出師徒分工 |
| 鍋旁的嘗試 | 水持續冒泡、康康反覆舀起又倒回去；師傅仍在接待客人 | 第2段 | 結合情境與動作理解「十分慌張」；另有不計分的同理討論 |
| 往鍋底找原因 | 多次舀水仍無效，轉向觀察鍋下熱源 | 第2、3段 | 把結果與持續燃燒的柴火連起來推論 |
| 找出解決的關鍵 | 用工具抽出一些柴火，火漸小；康康用心記住 | 第3、4段 | 比較方法並統整解決問題的道理 |

水泡、漣漪、蒸氣、舀水回倒和抽柴為原文動作的視覺化。人物造型、廚房擺設和環境聲是示意；不新增人物內心獨白，不把「十分慌張」推演成驚恐或危險事件。未呈現原文沒有的湯水噴出鍋外，也沒有遊戲內時間壓力、扣分或扣體力。第三場把視線從水面移到爐口，第四場對照火勢與水面的變化，支持學生從表面現象走向根本原因。

## 教材與原文界線

核對來源為使用者放在公開 repo 外的 `G3A/01課文word檔/115國語3上課文.docx`、`G3A/15閱讀理解提問/3上L04閱讀理解提問-水滾了.doc`，以及郭富華老師文本分析提問單（教用）。官方理解題第1題參考答案寫「澆水」，本次依課文正本及原有核准題庫的「燒水」處理，未改寫原有教材 JSON。

所有原句仍透過既有 `classroomKey.js` 的 AES-GCM 解密流程取得。新資料只存段句索引和 SHA-256 前8碼；開場逐句驗證，版本不符就停止出題。沒有明碼原句、教室密碼、官方檔案或測試解鎖入口加入 repo。QA 使用教師提供的本機原文生成一次性測試密文，僅攔截測試瀏覽器回應，不更改正式加密檔。

## 檔案與維護

- `src/data/firstPersonLesson.js`：單課場景、導讀、題目、選項錯因、三層提示、教材依據與原句索引。更動學習內容時增加 `version`，避免沿用舊完成紀錄。
- `src/activities/firstPersonCore.js`：進度與作答判定。進度使用 `mandarin:explore:<lessonId>`，與原有星星和測驗分開。
- `src/activities/firstPersonScene.js`：Three.js 第一人稱場景、程序材質、人物、蒸氣、水泡與動作。沿用 Review-Games 本地 Three.js、RoundedBoxGeometry、RoomEnvironment 與 RG3DKit 材質／光線工具，Vite 會打包本地資源。
- `src/activities/firstPersonMotion.js`：鍋沿／水位、人物肩部與握點的共用尺寸；四秒一循環的入水、抬起、傾倒、回位，以及兩節手臂的關節計算。鍋沿約為人物高度的54%，手掌留在鍋外；鍋與勺碗皆為有內壁的中空幾何。
- `src/pages/FirstPersonPage.js`、`src/styles/first-person.css`：探索介面、閱讀面板、正常密碼門、聲音與動畫設定。離開頁面會清理動畫、音訊、監聽與 WebGL。
- `src/main.js`、`src/pages/LessonDashboard.js`：路由與單課入口。
- `scripts/test-first-person.mjs`：可獨立執行的資料、正解、提示、順序與儲存容錯測試。
- `scripts/test-first-person-motion.mjs`：抽查1601個姿勢，驗證手掌不進鍋、不穿頭部、固定臂長與握持距離、倒水回鍋，以及動作循環的連續性。這些幾何檢查仍須搭配實際多角度截圖檢視。

新增課程時先確認官方原文、答案及段句索引，擴充資料查找，再提供相應的場景道具與觀察動作；不要複製一整份頁面。題目需同時有正解依據、逐項錯因與三層提示。

## 操作與降級

點圓點或線索按鈕先觀察，再按「讀課文」；閱讀兩個線索後開啟挑戰。答錯保留已讀線索並給提示。可關閉閱讀面板回到場景、重看原文或重玩目前場景；重玩不刪除先前完成紀錄。音效預設關閉，動畫尊重系統減少動態與遊戲設定；閱讀面板打開、頁面隱藏時暫停環境動態，沒有依賴動畫計時的關卡判定。3D 失敗時保留本地 SVG 與相同閱讀流程。

本機驗收截圖與詳細結果放在本次工作階段的 outputs，未加入公開 repo。實機 iPad／教室電腦效能、音量與臺灣國語朗讀仍需教師確認。程式驗收不能代替學生實際試玩或情緒理解的教學成效評估。

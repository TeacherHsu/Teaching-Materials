### 要 Claude 實玩的步驟（尚未執行）

在 `apps/mandarin` 啟動 `npm run preview:draft -- --host 127.0.0.1 --port 4176`，以Vite顯示的base網址加 `#/lesson/115AG3H04/explore`。使用正常教室密碼門，不加旁路，不把密碼或含課文截圖提交repo。桌機1366×900、手機375×812、平板820×1180各走一遍；另以實機iPad確認。

1. **幕1平常的早晨**：先點風鈴，預期可見擺動；設定開音效後再點，應聽到短風鈴聲，關音效後仍有視覺回饋。沿場景找到三根木柴，依序拖到柴堆；再重玩用「點木柴→點柴堆」完成。拖錯位置應彈回、有溫和提示、不扣水滴。三根收完才出第1段全文，關面板後場景仍在；答一題分工，錯答有錯因與三級提示，答對有水滴與下一幕。
2. **幕2水滾了**：拿勺子，依亮框「入水→舀起→鍋上方→倒回鍋中」，重複三次；每步可拖勺子到亮框，或點勺子再點亮框。預期勺子由空變盛水再變空，位置隨步驟更新；沸水／蒸氣與慌張臉不減弱。第三次應先看到溫和的無效回饋，再出三張同人物表情卡。選悠閒／放心應有錯因，選十分慌張後才顯示第2段全文；不另出第二題。檢查空勺／盛水切換及倒回位置是否清楚，不能只驗證步數有增加。
3. **幕3找原因**：依序點水面、勺子、火紅木柴。前兩項有觀察回饋且不降熱；木柴應有聚焦及柔和發現效果，再出唯一推論題。原文未出現的方法不得成為可操作選項。答對後解鎖第3段全文。檢查發現效果在面板出現前看得見，沒有加人物對話。
4. **幕4釜底抽薪**：進入先看約2.4秒師傅抽柴前／後插畫淡入，再恢復供學生操作的起始畫面。拿火鉗拖到「抽到爐外」亮框，每次抽一根；點選替代為「點火鉗→點目前柴火→點爐外」，共三根。每次柴火少一根、火焰與泡泡逐漸變少、蒸氣變淡；全部抽完爐口無火、水面平靜。解鎖第4段，完成事件排序（舀水→抽柴→水不再沸騰），預期有水滴及成語卡，卡上說明句由正常解密原文顯示。
5. **全幕共同檢查**：每步拖曳途中左右環顧不得漂移；放下後可再環顧。逐個Tab／Enter完成相同流程，焦點要可見且物件會移入視野；觸控目標至少44px。提示／閱讀／工具列不得蓋住當前物件及亮框，特別查手機底部、風鈴上方、幕4爐外目標。確認沒有水平捲動、外部請求、主控台錯誤或three載入。

# 課文樂園 UX／特教易用性／無障礙優化（2026-10-04）

## A. 現況盤點發現
- 課程首頁已有「下一步」卡與核心／加練分區，但沒有「建議順序」的整體視圖，也沒有跨次進入的「繼續學習」。
- 沒有投影模式：投影時全站導覽、麵包屑、提示列與題目同重；只能用瀏覽器縮放（等比放大、會破版）。
- axe（wcag2a/aa＋best-practice）：
  - 全頁：header／footer 包在 `role=main` 裡（landmark-*-is-top-level）。
  - 「本關小方法」標籤白字配 #d4723f，對比 3.4:1。
  - 生字卡、語詞卡外框是 role=button 又包著喇叭鈕（nested-interactive）。
  - 語詞卡圖片 alt 與畫面上的語詞重複（image-redundant-alt）。
  - 「下一步」徽章白字配模組色，對比不足。
- 答對只顯示「答對了！」；資料裡現成的 explanation 只在被揭曉答案時才出現。
- 圖示：已有一套大項圖示（`components/icons.js`，插圖＋SVG 後備），大項卡片與關卡頁共用，不需要第二套。
- 進度：localStorage（`storage.js` 星星／完成；`deviceSettings.js` 依學生代碼的組別與設定）。

## F. 教師模式／學生模式評估
1. 架構適合：所有頁面同一套元件，模式只需讀一個設定、切 class 或少數條件（已用同手法做上課模式、題組列開關）。
2. 影響範圍：首頁、課程首頁（隱藏加練區、只留建議順序＋繼續）、關卡頁（題組列、換題組）。題目元件不用動。
3. 可共用：上課模式 CSS、建議順序、StepJump 開關、教師頁組別細項。
4. 值得做，但建議先觀察兩週：建議順序＋繼續學習上線後，若學生仍常迷路再做「我要自己練習」的精簡入口。
5. 建議下一階段，以教師頁一個「學生端精簡畫面」開關實作，不另做兩套入口。

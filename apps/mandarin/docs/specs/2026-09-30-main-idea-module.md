# 新大項「抓重點」設計規格（草案，待 CF 核可）

日期：2026-09-30｜提案：家中 Mac／Claude｜狀態：**待審，尚未實作**

取代已移除的「課文地圖」。移除理由見本檔 §1。

## 1. 為什麼移除課文地圖

- **本站沒有課文全文**（版權界線）。文章結構教學的效果建立在「邊看文本、
  邊建立結構對應」；離開文本做標籤配對，練到的是猜詞，不是理解。
- **二上、三上的官方結構幾乎都是「起因／經過／結果」**，十二課反覆同一組詞，
  學生做兩課就能不讀而全對，測不到理解。
- **一上官方結構表沒有結構角色**，只有課文原句；出版社自己就不在這個年段做
  結構分析。
- 官方「課文結構表」放在**備課資料**底下，本來是教師分析用，不是學生活動。
  把教師工具直接轉成學生題目，這個轉換未經檢驗。

## 2. 新大項要解決什麼

以**摘要策略（summarisation）**為核心：區分「主旨」與「細節」。
這是閱讀理解教學中證據支持最強的策略之一，而且**可遷移**——換一篇文章還能用。

選它還有兩個現實理由：

- **素材五冊齊備**：55 課全部都有 `main_idea`（主旨＋大意）與
  `paragraph_summary`（段落大意），來源是官方「主旨、課文大意、段落大意」，
  每一冊都有這個資料夾。不像結構表有空白模板與整冊缺角的問題。
- **不需要課文全文**：段落大意本身就是文本的合法代理，學生在課堂上剛讀過
  課本，這裡做的是「把讀過的內容收攏成一句話」。

## 3. 任務設計：三階，一個畫面一個任務

### 第一階 讀段落大意（不作答）

依序呈現該課 3–6 張段落大意卡，每張附朗讀按鈕。
目的是喚起剛讀過的課文內容，建立後續判斷的基礎。

### 第二階 找出最重要的一段（細節 vs 重點）

從該課段落大意中選出「最能代表整課」的一段。
- 正解：與 `main_idea.gist` 語意最接近的那一段（由教師核准指定，不由程式猜）。
- 這一階訓練「不是每一段都一樣重要」，是摘要的第一步。

### 第三階 選出課文大意（核心）

給四個選項，選出最能代表全課的一句：

| 選項類型 | 來源 | 教學意義 |
|---|---|---|
| 正解 | `main_idea.gist` | 完整、概括全文 |
| 誘答 A：**以偏概全** | 某一段的段落大意 | 學生最常犯：拿一個細節當主旨 |
| 誘答 B：**太空泛** | 套用任何課都成立的句子 | 第二常犯：講了等於沒講 |
| 誘答 C：**偏離** | 與本課主題相關但非本課內容 | 檢核是否真的讀懂 |

誘答 A 直接取自該課資料，不需另外撰寫；B、C 需撰寫並經教師核准。

答錯先給提示（「這句話有沒有講到整課，還是只講了其中一段？」），
第二次才揭曉，沿用既有設計底線。

## 4. 資料模型

```json
"main_idea_task": {
  "key_paragraph_id": "paragraph_summary:...",   // 第二階正解，教師指定
  "distractors": [
    { "id": "...", "type": "partial", "text": null, "from": "paragraph_summary:..." },
    { "id": "...", "type": "vague",   "text": "<改寫後文字>", "status": "approved" },
    { "id": "...", "type": "offtopic","text": "<改寫後文字>", "status": "approved" }
  ]
}
```

- `partial` 型誘答不存文字，直接引用該課段落大意，避免重複與不同步。
- `vague`、`offtopic` 是新撰寫內容（非出版社文字），仍走 `rewrite-queue` →
  教師核准流程，`status` 未達 `approved` 不呈現。
- `key_paragraph_id` 必須由教師指定；未指定時第二階不出現，只跑第一、三階。

## 5. 閘門

- 三階都要求 `main_idea.status === 'approved'`。
- 第三階需要至少 2 個 `approved` 誘答才出題（正解＋2 誘答＝3 選項）。
- 段落大意少於 3 段的課次不出第二階。
- 不足時整個大項顯示「教材準備中」，不以任何方式猜補。

## 6. 為什麼不是別的

- **段落大意排序**：與既有「句子排序」操作重複，且敘事順序多半可由常識推出。
- **閱讀理解提問**：已有「閱讀理解」大項使用官方提問。
- **自我提問策略（QAR）**：值得做，但需要學生對答案來源分類，
  認知負荷高於本案，建議列為後續階段。

## 7. 驗收條件

- 五冊 55 課皆可判定狀態（可出題／教材準備中），無一課例外崩版。
- `npm run validate`、`build`、`check-dist`、`check-workflow` 通過。
- 新增回歸測試：
  - `test-main-idea-gate.mjs`：閘門條件與未核准內容不外流。
  - `test-main-idea-distractors.mjs`：誘答型別齊備、`partial` 確實引用本課段落。
- 375px 無橫向溢位；正文 ≥22px；朗讀按鈕只放喇叭圖示。

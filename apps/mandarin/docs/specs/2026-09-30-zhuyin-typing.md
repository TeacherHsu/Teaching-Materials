# 新大項「注音高手」設計規格（草案，待 CF 核可）

日期：2026-09-30｜狀態：**待審，尚未實作**

源自 CF 既有的實務：`teacherhsurc.blogspot.com` 上每課一頁的生詞拼音練習
（引擎為雄老師的 HTML5 FUN「注音高手」，該頁只放題庫設定）。本規格是
**在本站自行實作同一個教學概念**，不使用也不複製該引擎程式碼——它是第三方
作品，放進公開 repo 會有授權與姓名標示問題，而且無法套用本站的設計規範
（22px 正文、朗讀鍵、鷹架層級、計分與紀錄）。

---

## 1. 為什麼值得做

**本站目前十個大項全是「再認」，沒有任何「產出」活動。** 選擇、配對、拖曳
都是從給定選項中挑一個；學生可以靠刪去法通過，卻不見得真的會。

注音打字是唯一的產出型活動：聽到音，要自己把聲符、韻符、聲調一個一個打出來，
沒有選項可以猜。它練的是**聲韻覺識與注音符號自動化**——這正是閱讀困難學生
最常卡住的地方，也是識字的地基。

和既有大項的關係是互補而非重疊：

| 大項 | 方向 | 型態 |
|---|---|---|
| 看字選音 | 字 → 音 | 再認 |
| **注音高手** | **音 → 符 → 字** | **產出** |
| 一字多音 | 詞 → 音 | 再認 |

---

## 2. 流程（每一題）

1. **聽語詞**：播放語詞讀音（既有 SpeakButton／台灣國語語音），可重聽。
2. **看圖**：顯示該語詞的縮圖（`words[].image`，822 個語詞全部都有）。
   圖片是語意支持，讓學生知道在拼哪個詞，不是裝飾。
3. **打注音**：用畫面上的注音鍵盤逐字輸入。
4. **選字**：從候選國字中選出正確的字（見 §4 難易度）。
5. 完成整個語詞 → 下一題。

國字預設**不顯示**（沿用原設計的 `show_character = false`），否則變成抄寫。

---

## 3. 注音鍵盤

**採大千（標準）鍵盤排列，與實體鍵盤一致**，這樣練習可以遷移到真的打字。

```
ㄅ ㄉ ˇ ˋ ㄓ ˊ ˙ ㄚ ㄞ ㄢ ㄦ
 ㄆ ㄊ ㄍ ㄐ ㄔ ㄗ ㄧ ㄛ ㄟ ㄣ
  ㄇ ㄋ ㄎ ㄑ ㄕ ㄘ ㄨ ㄜ ㄠ ㄤ
   ㄈ ㄌ ㄏ ㄒ ㄖ ㄙ ㄩ ㄝ ㄡ ㄥ
```

- 一聲不佔鍵（空白），與實體注音輸入相同。
- 每鍵觸控範圍 ≥44px（設計底線），手機直式可橫向捲動或縮小字級，
  但**不得改變排列順序**——順序本身就是要學的東西。
- 接受實體鍵盤輸入：有鍵盤的載具直接打字，畫面上對應鍵同步高亮。

## 4. 難易度（CF 指定）

沿用 `utils/deviceSettings.js` 的三段層級。**注音輸入本身不分級**（音就是音，
不能給選項），分級落在**選字階段的候選字數量**：

| 層級 | 候選國字數 | 說明 |
|---|---|---|
| 支持 | 3 | 範圍小，容易找到目標字 |
| 標準 | 5 | |
| 挑戰 | 8 | 高頻同音字多，必須真的認得字形 |

候選字組成：**正確答案 ＋ 高頻干擾字，全部亂序排列**。

干擾字的取法（優先序）：
1. **同音字**（注音完全相同）——最有教學價值，逼學生分辨字形
2. **音近字**（僅聲調不同）
3. 其餘高頻字補滿

高頻字表由**本站自己的語料**統計產生（全五冊語詞與生字，共 1112 個字），
不另外引入外部字表——這樣候選字一定是學生看過或將學到的字。

## 5. 鷹架

| 時機 | 支持 |
|---|---|
| 隨時 | 重聽語詞、看圖 |
| 按「提示」 | 顯示**聲符**（第一個符號），沿用 CF 原設計 |
| 再按「提示」 | 顯示韻符 |
| 按「跳過」 | 跳過這一題，記為未完成，不中斷流程 |

「跳過」是必要的：卡住時沒有出口，對 ADHD 與挫折容忍度低的學生會直接放棄整個活動。

策略卡（`activities/strategyCards.js`）新增一句：
**「先聽清楚第一個音，找出聲符；再聽韻母和聲調。」**

## 6. 資料需求與現況

| 冊別 | 語詞 | 有注音 | 缺 |
|---|---|---|---|
| 一上 115AG1H | 71 | **71** | 0 |
| 二上 115AG2H | 194 | 0 | **194** |
| 三上 115AG3H | 177 | 66 | **111** |
| 四上 115AG4K | 185 | 183 | 2 |
| 六上 115AG6H | 195 | **195** | 0 |

822 個語詞**全部都有縮圖**，注音則只有 515 個。

因此：

- **一上、四上、六上（449 語詞）可以立刻上線。**
- 二上、三上缺注音，該冊顯示「教材準備中」，不猜補。
  語詞注音涉及變調與輕聲（例如「一」「不」），由單字讀音機械拼接會出錯，
  必須從官方「形音輕鬆學（含語詞解釋）」取得——五冊大補帖都在
  `~/mandarin-work/<冊別>/raw/大補帖/`，屬於後續匯入工作。

## 7. 計分與紀錄

沿用既有機制，不另立一套：

- 第一次就打對 → `firstTry`
- 用過提示但自己打對 → 仍算自己答對（星星不扣，見精熟導向規則）
- 跳過或被揭曉 → `revealed`
- 正確率（教師端）＝第一次就打對的比率

---

## 8. 驗收條件

- 鍵盤排列與大千標準完全一致（回歸測試逐鍵比對）。
- 候選字必含正確答案、互異、數量符合當前層級。
- 沒有注音的語詞不得出題（fail-closed）。
- 375px 無橫向溢位；鍵盤每鍵觸控範圍 ≥44px。
- `npm run validate`、`build`、`check-dist`、`check-workflow` 通過。

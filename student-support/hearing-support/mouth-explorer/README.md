# 嘴巴探險隊（注音發音位置練習）

給國小聽語障學生用的發音位置練習遊戲。純靜態網頁，沒有建置步驟，直接開 `index.html` 就能用。

## 玩法

- **自由探索**：拖拉嘴唇、下巴、舌尖、舌面，點「鼻」開關鼻子通道；下方會用白話說出現在的嘴型，並猜它像哪個注音。
- **點注音**：右下角注音鍵盤，點一個符號就播放這個音的口腔動作，並顯示步驟、氣流強弱、喉嚨震不震動、鼻子有沒有出氣。
- **輸入國字**：最多 12 個字，自動查注音並逐字播放；破音字再點一次可以換讀音。
- **模仿挑戰**：照著黃色虛線提示，把嘴型拖到目標位置，全部打勾就得到一顆星星。
- **照鏡子**：開啟前鏡頭對照自己的嘴型。畫面只在本機顯示，不錄影、不上傳。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css`、`app.js` | 頁面、樣式、主程式（無外部相依） |
| `zhuyin-data.js` | 字／詞 → 注音對照表，**自動產生，不要手改** |
| `tools/build-data.py` | 產生 `zhuyin-data.js` 的腳本 |

## 資料來源與限制

- **字音**：教育部《重編國語辭典修訂本》公眾授權資料（創用CC 姓名標示-禁止改作 3.0 臺灣），取自 [g0v/moedict-data](https://github.com/g0v/moedict-data) 的 `dict-revised.json.xz`。腳本只擷取字詞與注音，不改動讀音。
  - 單字的預設讀音＝這個字在辭典詞條裡最常出現的讀音；少數常用虛詞（的、了、和……）在腳本的 `PREFER` 指定口語讀音，讀音本身仍出自辭典。
  - 斷詞只用「最長詞優先」，破音字可能選錯，所以畫面上保留手動換讀音。
- **發音部位與方法**：採一般國語語音學的分類（雙唇、唇齒、舌尖、舌根、舌面、翹舌、平舌；塞音、塞擦音、擦音、鼻音、邊音；送氣與否）。製作時無法連上教育部《國語注音符號手冊》逐條核對，**請老師或語言治療師上線前看過 `app.js` 裡的 `CONS`、`STEPS`**。
- **剖面圖**：是簡化的示意模型（參考 chimera-vocal-synth 的「拖拉舌頭、嘴唇、下巴」與 dragology 的「拖拉時受模型限制」兩個概念，程式為自行撰寫），不是依 MRI 量測繪製，不能當成臨床評估工具。
- **語音**：使用瀏覽器內建的語音合成（zh-TW），各裝置的聲音與可用性不同。

## 重新產生字音資料

```sh
curl -LO https://raw.githubusercontent.com/g0v/moedict-data/master/dict-revised.json.xz
xz -d dict-revised.json.xz
python3 tools/build-data.py dict-revised.json
```
